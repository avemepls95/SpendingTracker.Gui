Автоматическая разметка

Незнакомое описание траты система отправляет в языковую модель и предлагает категорию, которую вы подтверждаете или отвергаете. Знакомые описания размечаются по вашим прошлым решениям и наружу не уходят.

@if (isUnlimited()) { Месячного лимита обращений к модели нет. } @else if (monthlyLimit() === 0) { Месячный лимит обращений к модели: 0. Разметки не будет даже с включённой отправкой описаний. Лимит задаёт владелец сервиса. } @else { Месячный лимит обращений к модели: {{ monthlyLimit() }}. Лимит задаёт владелец сервиса. }

Что уходит наружу

  • описания трат;
  • суммы и коды валют;
  • полное дерево названий ваших категорий;
  • до тридцати примеров вашей разметки (описание и категория).

Отправку описаний можно выключить в любой момент переключателем выше.

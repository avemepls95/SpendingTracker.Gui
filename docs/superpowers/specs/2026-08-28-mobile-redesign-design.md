# SpendingTracker.Gui - багфиксы и mobile-first редизайн

Дата: 2026-08-28
Ветка: `feature/redesign`

## Задача

Фронтенд трекера расходов написан джуниором. Требуется исправить баги и привести
интерфейс в порядок. Основной сценарий использования - телефон, преимущественно
внутри Telegram Mini App.

## Границы

В объёме:

- исправление всех дефектов из раздела "Дефекты";
- перевод проекта на Angular 21 LTS со standalone-компонентами и signals;
- переработка всех экранов под mobile-first;
- интеграция с Telegram Mini App (тема, safe-area, нативные кнопки, haptics).

Вне объёма:

- создание траты из интерфейса - на бэкенде нет эндпоинта, траты приходят из бота;
- изменения бэкенда;
- многоязычность - интерфейс остаётся русским.

## Ограничения

- Node на машине разработчика - v22.14.0. Angular 22 требует `^22.22.3`, поэтому
  целевая версия - **Angular 21.2.x LTS** (требует `^22.12.0`). Обновление Node
  не должно быть побочным следствием работы над фронтендом.
- Тестов в проекте нет ни одного. Проверка - сборка плюс ручной прогон сценариев.
- Контракт бэкенда недоступен: `swagger` на `api.moneytrace.pro` отдаёт 404.
  Поэтому разбор ответов должен быть устойчив к расхождению имён полей.

## Стратегия перехода на Angular 21

Прямое обновление 16 -> 21 означает пять последовательных мажорных миграций.
На 17->18 ломается вся темизация Angular Material: в коде десятки переопределений
вида `::ng-deep .mat-mdc-*`, которые опираются на внутренний DOM MDC.

Вместо миграции - чистый каркас на Angular 21 с переносом доменного слоя:

- переносится почти без правок: модели, DTO, мапперы, `SpendingApiService`,
  сторы, `LocalStorageManager` - это обычный TypeScript;
- переписывается в любом случае: компоненты, шаблоны, стили - их затрагивает
  редизайн независимо от версии Angular.

### Зависимости

Удаляются:

| Пакет | Причина |
| --- | --- |
| `bootstrap` | не подключён в `angular.json`, не используется |
| `uuid` | импортируется в одном DTO, значение не используется |
| `ngx-spinner` | дублирует собственный `LoaderComponent` |
| `ngx-infinite-scroll` | заменяется на `IntersectionObserver` |
| `moment`, `@angular/material-moment-adapter` | ~300 КБ и предупреждение сборки про CommonJS |
| `@auth0/angular-jwt` | используется один метод `isTokenExpired` |
| `ngx-mat-select-search` | выбор валюты становится собственным bottom sheet |

Остаются только `@angular/*`, `rxjs`, `tslib`.

### Использование Angular Material

Material остаётся точечно: диалоги, bottom sheet, snackbar, datepicker, меню.
Списки, карточки, чипы, таб-бар и кнопки делаются на собственных стилях поверх
дизайн-токенов. Причина - именно борьба с внутренним DOM Material породила
`::ng-deep`-хаки в текущем коде.

Токены Material M3 (CSS custom properties) связываются с токенами приложения,
поэтому оставшиеся виджеты Material наследуют тему, включая тему Telegram.

### Change detection

Приложение зоннless (`provideZonelessChangeDetection`), состояние - на signals.
Material 21 совместим с zoneless. Это убирает `zone.js` из полифилов.

## Дизайн-система

Токены на CSS custom properties: цвет, радиусы, тени, шаг сетки 4 px,
типографика, safe-area.

Тема выбирается по приоритету: явный выбор пользователя, затем `themeParams`
Telegram, затем `prefers-color-scheme`.

Суммы набираются шрифтом с табличными цифрами (`font-variant-numeric:
tabular-nums`), чтобы разряды выстраивались по вертикали в списке.

## Экраны

**Навигация.** Нижний таб-бар на пять пунктов вместо гамбургер-меню: один тап
вместо двух. Внутри Telegram собственный toolbar убирается, его роль выполняет
шапка Telegram.

**Траты** (главный). Список, сгруппированный по дням: заголовок дня с суммой за
день, строка - описание и чипы категорий слева, сумма с валютой справа. Дата в
строке не повторяется. Удаление - через свайп или меню в карточке траты, не
кнопкой в строке. Категории редактируются в отдельном bottom sheet, а не
разворачивающимся деревом внутри строки таблицы. Поиск закреплён сверху,
"без категорий" - чип-переключатель. Догрузка - `IntersectionObserver`, без
дублирующей кнопки "More".

**Счета.** Карточки: иконка типа, название, сумма в своей валюте,
конвертированная сумма вторичным текстом. Сверху общий баланс крупно.

**Аналитика.** Пресеты периода (месяц, три месяца, год, произвольный) и
горизонтальные столбцы по категориям вместо дерева цифр. Тап по категории
открывает bottom sheet с тратами. Явные пустые состояния: отдельно "за период
нет трат" и "траты есть, но не разнесены по категориям" - именно их отсутствие
делает текущий экран похожим на сломанный.

**Категории.** Список с редактированием на месте.

**Настройки.** Валюта отображения и переключатель темы.

## Обработка ошибок

`ErrorCodeMessages` возвращает `null` для неизвестного кода вместо исключения,
вызывающая сторона показывает общее сообщение. Разбор тела ошибки 400 проверяет,
что пришёл массив. Интерцептор токена продлевает сессию через
`refreshAuthToken()` с очередью параллельных запросов и уводит на авторизацию
только когда продление не удалось.
